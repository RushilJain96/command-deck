# Sprint 1 — Interaction Engine

## Goal

Build the foundation that powers the entire portfolio.

No content.
No projects.
No dashboard.

Only interaction.

---

## Deliverables

- Fixed viewport application
- Scene architecture
- Camera system
- Spacecraft component
- Mission node system
- Hover detection
- Ship rotation
- Target lock animation
- Basic transition framework

---

## Acceptance Criteria

- Ship smoothly rotates toward hovered mission.
- Hover interactions remain at 60 FPS.
- Viewport never scrolls.
- Scene architecture is reusable.
- Components are reusable.
- No placeholder portfolio content.

---
